## Run

```sh
python3 main.py
```

`main.py` (standard library only) copies the committed `entry.png`
(1024x1024, drawn with Pillow by `draw_poster.py`) to
`$MAKEFUN_OUTPUT_DIR/entry.png`. Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
